# Trabalho 1
### Instalar bibliotecas necessárias utilizando:

`pip install -r requirements.txt`

### Execute o programa utilizando o comando:

`python main.py`

### Entradas de dado ocorrem apenas enquanto o programa já está em execução, sendo pedidos:
- `string` - Nome da imagem a ser processado
- `int 0 ou int 1` - Se a imagem é colorida ou não
- `int` - Filtro desejado

### As imagens resultantes do processamento são salvas na pasta result
